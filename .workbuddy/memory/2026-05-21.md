## 2026-05-22 修复 GitHub Pages 路由跳转问题
- 问题：登录后跳转到 xan111333.github.io/dashboard（缺少 /AIGC-platform/ 前缀和 #/ hash）
- 根因：Login.vue、AppLayout.vue、Register.vue 中使用 window.location.href 绝对路径跳转，绕过了 Vue Router
- 修复方式：
  - src/router/index.js: createWebHistory → createWebHashHistory（hash 模式兼容 GitHub Pages）
  - Login.vue: 添加 useRouter，window.location.href → router.push()
  - AppLayout.vue: 添加 useRouter，window.location.href → router.push()
  - Register.vue: 添加 useRouter，window.location.href → router.push()
- 部署：npm run build → git add -f dist → commit → git subtree split → force push gh-pages
- 结果：URL 变为 https://xan111333.github.io/AIGC-platform/#/dashboard 形式，可正常访问
