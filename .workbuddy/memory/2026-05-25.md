## 修复 404（2026-05-25）

**问题**：GitHub Pages 404，原因是旧 dist 未包含最新构建（dist 在 .gitignore 中，subtree split 未检测到变更）。

**解决方案**：
1. `npm run build` 重新构建
2. `git add -f dist/` + `git commit` 将新 dist 临时提交到 main
3. `git branch -D gh-pages-deploy` 删除旧临时分支
4. `git subtree split --prefix dist -b gh-pages-deploy` 基于新提交 split
5. `git push origin gh-pages-deploy:gh-pages --force` 强推到 gh-pages（`741e08a`）
6. `git revert HEAD && git push origin main` 撤销 main 上的临时 dist commit

**gh-pages 最新 commit**：`0875a15`

## 修复学生任务弹窗无法打开（2026-05-25）

**问题**：`StudentTasks.vue` 中 `el-dialog` 使用 `:visible.sync`（Vue 2 Element UI 语法），在 Vue 3 Element Plus 中不生效，导致任务详情弹窗打不开，无法查看和提交。

**修复**：将 `:visible.sync="showDetail"` 改为 `v-model="showDetail"`（Element Plus 正确语法）。
