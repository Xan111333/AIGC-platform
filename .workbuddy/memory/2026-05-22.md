## 修复图片生成裂图问题

**问题原因**：`src/views/ImageGenerate.vue` 中读取 API 返回结果时使用了错误的字段名 `result.result_url`，而实际 API (`src/api/index.js`) 返回的字段是 `image_url`。导致图片 URL 为 `undefined`，浏览器渲染为裂图。

**修复内容**：
1. `ImageGenerate.vue` `handleGenerate`：
   - `result.result_url` → `result.image_url`（关键修复）
   - 新增 `styleMap` 对象，将英文 style value 转为中文风格描述，拼接到提示词中
   - 支持多张图片循环生成（按 `params.count` 次数调用 API）
   - 增强错误提示：余额不足、CORS 问题、其他错误分别给出清晰提示
   - 移除静默 fallback 到 mock 图片的行为，改为明确报错

2. 重新构建并部署到 GitHub Pages（gh-pages 分支）

**部署状态**：已成功推送 `ac149cc` 到 gh-pages
